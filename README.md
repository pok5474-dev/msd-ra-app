# 근골격계 유해요인조사·위험성평가 웹앱

휴대폰·태블릿·PC 브라우저에서 여는 오프라인 웹앱입니다. **이 저장소에는 사업장 자료가 없습니다(빈 양식).**
입력한 자료는 각 기기의 브라우저 안에만 저장되며 서버로 전송되지 않습니다.

- 여는 주소: GitHub Pages 주소 (저장소 Settings → Pages)
- 홈 화면에 추가: 안드로이드 Chrome ⋮ → '홈 화면에 추가' / 아이폰 Safari 공유 → '홈 화면에 추가'
- 사업장 자료: 보건관리 담당자가 나눠 준 백업 파일(.json)을 처음 한 번 불러옵니다.
- 업데이트: `index.html`, `sw.js`를 바꾸면 사용자 화면에 '새 버전 → 지금 적용'이 뜹니다. 입력 자료는 유지됩니다.
